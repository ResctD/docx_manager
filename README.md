# docx_manager

Инструмент для автоматизации работы с большим количеством документов.

Целевые функции:
1. Поиск всех документов с примечаниями
2. Вывод всех примечаний
3. Удаление всех примечаний
4. Поиск всех документов в режиме рецензиование


> Другие функции будут добавляться по мерей идей или проблем
